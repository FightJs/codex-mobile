# Static Pages demo

Prerequisite: serve `demo/` with any static HTTP server or open the deployed Pages URL.

1. Open the page and verify the synthetic-data and disconnected-feature notice is visible.
2. Open each sample thread and Skills Hub; confirm their content and demo limitations are displayed. Refresh each hash route and confirm it remains visible.
3. At 375×812 and 768×1024, check navigation and layout. Repeat in light and dark system themes.
4. Confirm there are no API, WebSocket, or Codex session requests. Nothing is saved or sent.

Cleanup: stop the static server if one was started. The preview does not modify application data.
